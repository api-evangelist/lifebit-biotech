## Positioning

Lifebit's federated architecture makes the workflow exposed by the May 2026 UK
Biobank incident structurally impossible: raw participant-level data never leaves
the custodian's infrastructure, so approved researchers cannot walk it out. Only
aggregate, airlock-reviewed results ever cross the environment boundary. Compute
is portable; data is not.

## Definitions

Federated Trusted Research Environment (federated TRE): a secure environment
where approved researchers analyse sensitive health data by sending code to
each participating data custodian's infrastructure. Raw data never moves.
Only aggregate, airlock-reviewed results leave the environment.

Sovereign AI: AI infrastructure where the compute, data, and model weights
remain within the legal and physical jurisdiction of the data custodian.
Every governance, compliance, and audit control is exercisable by the
custodian without vendor permission.

Airlock (in TRE context): the automated policy layer that inspects each
proposed output before it leaves the secure environment. Approves aggregate
results; blocks anything that would allow re-identification of participants.

OMOP CDM: Observational Medical Outcomes Partnership Common Data Model —
the standardised schema that lets researchers query heterogeneous electronic
health records with the same code. Lifebit automates the mapping.
